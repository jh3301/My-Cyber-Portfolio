# 🗄️ SQL Security Labs

A collection of hands-on database querying, log analysis, and security investigation labs.

---

## 📂 Labs in this Section

* **01. Performing a SQL Query**
  * **Objective:** Retrieve employee device information to determine required system updates, inspect user login activity for potential anomalies, and organise returned records chronologically using SQL queries.

* **02. Filtering a SQL Query**
  * **Objective:** Query database tables using `SELECT` and `FROM`, apply `WHERE` clauses to identify machines requiring OS updates and staff in specific departments, and use the `LIKE` operator to pattern match office locations.

* **03. Applying More Filters in SQL**
  * **Objective:** Investigate security incident authentication logs using comparison operators (`>`, `>=`, `<`) and the `BETWEEN ... AND` range operator across dates, times, and numeric event IDs.

* **04. Applying Complex Filters in SQL (AND, OR, and NOT)**
  * **Objective:** Apply complex logical operators (`AND`, `OR`, `NOT`) alongside `LIKE` pattern matching to isolate after-hours failed authentication events, audit specific multi-day log windows, exclude international traffic, and filter departmental assets for system updates.
